# Jornada da Liberdade

Página de vendas do Workshop Raio-X do Ciclo Financeiro, de Cezar Linzmeyer.

## Tecnologias

React, TypeScript e Vite.

## Rotas

- `/a1`
- `/a2`
- `/a3`
- `/obrigado`

As três páginas de vendas compartilham estrutura, conteúdo e componentes. Somente a comunicação principal do topo varia entre elas.

## Execução local

```bash
pnpm install
pnpm dev
```

## Build de produção

```bash
pnpm build
```

O resultado é gerado na pasta `dist`.

## Configuração pendente

O endereço de checkout deve ser informado antes da abertura das vendas. Data, horário, canal de envio dos acessos e contatos de suporte também aguardam confirmação.
